Manual de usuario para empleados

Guía práctica para gestionar el catálogo, el inventario, las ventas, los pedidos, los clientes y los empleados.

1. Acceso al sistema

  1. Abre la dirección de TiendaWeb en tu navegador.
  2. Escribe el correo electrónico y la contraseña asignados.
  3. Pulsa Entrar. Si los datos son correctos aparecerá el panel de administración.
Seguridad: no compartas tus credenciales. Usa Cerrar sesión al terminar, especialmente en equipos compartidos.

2. Navegación y permisos

La barra lateral permite cambiar de módulo. Las opciones visibles dependen del rol asignado:

MóduloUso principalAcceso

3. Artículos y catálogo

Crear un artículo

  1. Entra en Artículos y pulsa Nuevo artículo.
  2. Escribe el nombre, el precio y los detalles del producto.
  3. Selecciona una imagen o pega una URL de imagen válida.
  4. Pulsa Guardar artículo y comprueba que aparece en la lista.

Editar o eliminar

Usa Editar en la tarjeta del producto para modificar sus datos. Para eliminarlo, pulsa Eliminar y confirma la operación. La eliminación es permanente en el catálogo.

4. Inventario

El módulo muestra el total de artículos, las unidades disponibles y los artículos sin stock.

  • Usa el buscador para localizar un producto.
  • Usa el filtro para ver todo el stock, stock medio, bajo stock o productos sin existencias.
  • Pulsa + o - para ajustar una unidad.
  • Pulsa el botón de edición para introducir la cantidad y el precio exactos; después selecciona Guardar.
  • Pulsa Actualizar para consultar los datos más recientes del servidor.
Recomendación: revisa que la cantidad sea correcta antes de guardar. Las cantidades no pueden ser negativas.

5. Registrar una venta

  1. Abre Ventas y busca el producto en el catálogo.
  2. Pulsa Agregar. La cantidad se limita automáticamente al stock disponible.
  3. Revisa el carrito y cambia la cantidad si es necesario.
  4. Escribe el nombre y el correo del cliente.
  5. Selecciona el estado inicial del pedido.
  6. Pulsa Confirmar venta. El sistema mostrará el número del pedido y actualizará el catálogo.

Para retirar un producto del carrito, pulsa Quitar. Antes de confirmar, comprueba el total y las unidades.

6. Gestionar pedidos

En Pedidos puedes buscar por número o cliente y filtrar por estado.

  • Pendiente: el pedido todavía requiere atención o entrega.
  • Entregado: el pedido se ha completado.

Usa el botón de acción de cada fila para alternar el estado. Espera a que termine la actualización antes de repetir la acción.

7. Clientes

Este módulo está disponible para administradores y encargados. Puedes registrar nombre, documento, correo, teléfono y datos de contacto. Usa los filtros para separar clientes activos e inactivos.

Al dar de baja un cliente, confirma solo después de verificar su identidad. Los datos mostrados en la tabla incluyen enlaces directos para correo y teléfono.

8. Empleados

Este módulo está disponible para administradores y encargados. Permite registrar o modificar empleados y asignar la categoría Encargado o Vendedor.

  • Para un empleado nuevo, define una contraseña de al menos seis caracteres.
  • Al modificar un empleado, deja la contraseña vacía para conservar la actual.
  • Usa el estado para activar o desactivar una cuenta sin borrar el registro.
  • Usa Dar de baja solo cuando corresponda y confirma la operación.

9. Problemas frecuentes

SituaciónQué hacer
No puedo iniciar sesiónComprueba el correo, la contraseña y que el teclado no tenga activado Bloq Mayús. Si continúa, contacta con un administrador.
No aparecen datosComprueba la conexión y pulsa Actualizar. Si el problema continúa, informa del módulo y la hora del error.
La sesión ha caducadoVuelve a iniciar sesión. El sistema cierra la sesión automáticamente cuando el servidor rechaza el token.
No puedo acceder a Clientes o EmpleadosSolicita al administrador o encargado que revise tu rol.
Una operación devuelve un errorNo repitas muchas veces la acción. Anota el mensaje, verifica los datos y comunícalo al responsable.

10. Buenas prácticas

  • Comprueba nombres, precios, cantidades y cliente antes de guardar.
  • No abras varias operaciones simultáneas sobre el mismo pedido o producto.
  • Usa imágenes claras y enlaces accesibles para el catálogo.
  • Cierra la sesión al finalizar y no guardes contraseñas en equipos compartidos.
  • Reporta errores con el módulo, la acción realizada y el mensaje mostrado.
